# 🔐 Criador de Senhas

Projeto desenvolvido em Python durante os estudos na Alura.

## 📌 Sobre o projeto

Este programa cria senhas aleatórias utilizando:

- Letras maiúsculas e minúsculas
- Números
- Caracteres especiais

O usuário escolhe o tamanho da senha e o programa gera uma senha aleatória.

## 🚀 Como executar

É necessário ter o Python instalado.

Execute no terminal:

```bash
python criador_senhas.py
